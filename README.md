# Python Quiz

Python으로 만든 콘솔 기반 수도 퀴즈 게임입니다. 퀴즈를 풀고 점수를 확인할 수 있으며, 실행 상태는 JSON 파일에 저장됩니다.

## 주요 기능

- 저장된 퀴즈 풀기
- 퀴즈 제목 목록 확인
- 퀴즈 추가 및 삭제
- 힌트 보기 기능
- 힌트 1회당 10점 감점
- 획득 점수 확인
- 퀴즈와 점수를 `state.json`에 저장하고 불러오기
- 저장 파일이 없거나 올바르지 않을 때 기본 퀴즈 사용

## 파일 구조

```text
Python_Quiz/
├── docs/
│   └── history.md       # 기능별 개발 기록
├── default_quiz.py      # 기본 퀴즈 데이터
├── input.py             # 숫자와 문자열 입력 처리
├── main.py              # 프로그램 시작점
├── quiz.py              # 문제 출력, 정답 확인, 점수 계산
├── quiz_game.py         # 메뉴와 전체 게임 흐름 관리
├── state.json           # 퀴즈와 점수 저장 파일
├── storage.py           # 상태 저장 및 불러오기
└── README.md            # 프로젝트 사용 안내
```

## 실행 환경

- Python 3
- 별도의 외부 패키지는 필요하지 않습니다.

## 실행 방법

저장소를 내려받습니다.

```bash
git clone https://github.com/Beda28/2.Quiz.git
cd 2.Quiz
```

## 사용 방법

프로그램을 실행하면 다음 메뉴가 표시됩니다.

```text
1. 퀴즈 시작
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 퀴즈 삭제
6. 게임 종료
```

메뉴 번호를 입력해 원하는 기능을 실행합니다. 퀴즈에서는 정답이라고 생각하는 선택지 번호를 입력합니다. 힌트가 필요하면 0을 입력해 힌트를 볼 수 있으며, 힌트 1회당 10점이 감점됩니다.

## 데이터 저장

퀴즈 데이터와 최근 점수는 프로젝트 폴더의 `state.json`에 저장됩니다. 각 퀴즈는 제목, 선택지, 정답, 힌트를 포함하는 구조로 저장되며, 파일을 찾을 수 없거나 데이터 구조가 올바르지 않으면 `default_quiz.py`의 기본 퀴즈와 0점 상태를 사용합니다.
