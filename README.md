## 1. 문서 개요
#### 본 문서는 2번째 과제, 파이썬 퀴즈제작의 과정을 담은 문서입니다.

## 2. 공통 입력 처리
```bash
# 생성된 함수
read_int - 숫자값 입력 ( 정답처리에 사용 )
read_str - 문자값 입력 ( 퀴즈 등록에 사용 )

# 사용된 기능들
input("메시지")       - 메시지를 출력하고, 값을 입력받는다.
int()                - 함수 내부에 묶인것들을 int 타입으로 변환한다.
[변수].strip("필터값") - 지정된 변수를 필터값을 기준으로 잘라냈을때의 결과를 반환한다.
```

## 3. 퀴즈 정답 처리
```bash
# 생성된 함수
question - 기본 퀴즈 출력 / 후속 함수 호출
choices  - 전달받은 선택지 출력
answer   - 정답 입력받기 / 정답 처리

# 사용된 기능들
{}(딕셔너리) - 키와 값을 한 쌍으로 지정하며, 딕셔너리[키]를 사용해 해당 값을 가져올 수 있다.
```

## 4. 기본 퀴즈 제작
```bash
# 생성된 데이터
DEFAULT_QUIZZES - 딕셔너리로 구성된 기본 퀴즈 데이터

# 사용된 기능들
[](리스트) - 여러개의 퀴즈 딕셔너리를 순서대로 저장한다.
```
