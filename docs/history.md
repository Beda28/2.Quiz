# 개발 기록

Python 퀴즈 게임을 기능별로 구현하며 사용한 함수와 Python 기능을 정리한 문서입니다.

## 1. 공통 입력 처리

```text
# 생성된 함수
read_int - 숫자 입력 처리(정답 및 메뉴 입력에 사용)
read_str - 문자열 입력 처리(퀴즈 등록에 사용 예정)

# 사용된 기능
input("메시지") - 메시지를 출력하고 값을 입력받습니다.
int()           - 전달받은 값을 정수형으로 변환합니다.
문자열.strip()  - 문자열 양쪽의 공백을 제거합니다.
```

## 2. 퀴즈 정답 처리

```text
# 생성된 함수
question - 퀴즈를 순서대로 출력하고 점수를 계산합니다.
choices  - 전달받은 선택지를 출력합니다.
answer   - 정답을 입력받아 채점 결과를 반환합니다.

# 사용된 기능
딕셔너리({}) - 키와 값을 한 쌍으로 저장하고 딕셔너리[키]로 값에 접근합니다.
for            - 퀴즈와 선택지를 순서대로 반복합니다.
return         - 채점 결과와 최종 점수를 호출한 곳으로 돌려줍니다.
```

## 3. 기본 퀴즈 제작

```text
# 생성된 데이터
DEFAULT_QUIZZES - 딕셔너리로 구성된 기본 퀴즈 데이터입니다.

# 사용된 기능
리스트([])     - 여러 퀴즈 딕셔너리를 순서대로 저장합니다.
중첩 딕셔너리 - 제목, 선택지, 정답을 하나의 퀴즈로 구성합니다.
```

## 4. 퀴즈 상태 저장 및 불러오기

```text
# 생성된 함수
default_state - 기본 퀴즈와 초기 점수를 반환합니다.
loadstate     - state.json에서 저장된 상태를 불러옵니다.
savestate     - 현재 상태를 state.json에 저장합니다.

# 사용된 기능
Path                      - 파일 위치를 경로 객체로 관리합니다.
deepcopy                  - 원본에 영향을 주지 않는 복사본을 만듭니다.
with                      - 파일 사용이 끝나면 자동으로 파일을 닫습니다.
json.load                 - JSON 파일을 Python 데이터로 변환합니다.
json.dump                 - Python 데이터를 JSON 파일에 저장합니다.
try / except              - 실행 중 발생한 예외를 구분하여 처리합니다.
isinstance(데이터, 자료형) - 데이터가 지정한 자료형인지 확인합니다.

# 예외처리
FileNotFoundError - 파일을 찾을 수 없을 때
ValueError        - 데이터 구조가 잘못되었을 때
JSONDecodeError   - JSON 형식이 잘못되었을 때
OSError           - 파일을 읽거나 저장할 수 없을 때
TypeError         - 잘못된 자료형이 전달되었을 때
```

## 5. 퀴즈 게임 실행 및 점수 관리

```text
# 생성된 클래스
QuizGame - 메뉴 실행, 퀴즈 진행, 점수 확인 및 게임 종료를 관리합니다.

# 생성된 메서드
run            - 메뉴 선택에 따른 기능을 반복 실행합니다.
show_menu      - 퀴즈 게임의 메인 메뉴를 출력합니다.
play_quiz      - 퀴즈를 실행하고 결과를 저장합니다.
show_quiz_list - 저장된 퀴즈 제목 목록을 출력합니다.
show_score     - 현재 점수를 출력합니다.
exit_game      - 현재 상태를 저장하고 게임을 종료합니다.
clear_screen   - 화면 정리 명령어를 실행합니다.

# 사용된 기능
class     - 데이터와 함수를 하나의 객체로 묶습니다.
__init__  - 객체가 생성될 때 필요한 초기값을 설정합니다.
self      - 생성된 객체 자신의 값과 메서드에 접근합니다.
while     - 조건이 유지되는 동안 메뉴 실행을 반복합니다.
elif      - 앞선 조건이 거짓일 때 다음 조건을 확인합니다.
enumerate - 목록의 순번과 값을 함께 가져옵니다.
```

## 6. 최고점수 기능

```text
# 추가된 저장값
beat_score   - 최고 점수(백분율 기준)를 저장합니다.
best_correct - 최고 기록일 때 맞힌 문제 수를 저장합니다.
best_total   - 최고 기록일 때 전체 문제 수를 저장합니다.

# 사용된 로직
score / total * 100          - 맞힌 문제 수를 기준으로 점수 비율을 계산합니다.
self.state.get("beat_score") - 기존 최고 기록을 불러옵니다.
> best_score                 - 현재 점수가 최고 기록보다 높은지 비교합니다.

# 출력 내용
맞춘 문제 수: score/total
점수: score / total * 100
최고 점수: 저장된 beat_score
```
